# CarePoint Pharmacy

CarePoint Pharmacy is a modern responsive pharmacy website concept built with React and Vite.

This project was created as a portfolio/demo project to showcase a clean healthcare-focused user interface, responsive design, structured service sections, and a professional online presence for a local pharmacy business.

> **Note:** CarePoint Pharmacy is a concept/demo project created for portfolio purposes. It does not represent a real client or operating pharmacy.

## Features

- Modern responsive design
- Mobile-friendly layout
- Pharmacy-focused homepage
- Product and service presentation
- Clear call-to-action sections
- Contact and enquiry interface

## Getting Started

Clone the repository:

```bash
git clone https://github.com/SkylimitYc/Carepoint-pharmacy.git
```

Navigate to the project directory:

```bash
cd Carepoint-pharmacy
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## Build for Production

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
